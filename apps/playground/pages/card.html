Content-driven height

The card grows with its content — the glass surface, specular rim border, and box-shadow all scale correctly. No fixed height is required. Glass components at the Surface layer contain their own blur context, so tall cards don't cause backdrop-filter bleed into adjacent layers. 

<fluid-card>
  <h2 slot="header">Title</h2>
  <p>Long body text — card height is content-driven.</p>
</fluid-card>

Layout FLIP animation

Cards with the layout attribute use card.runFLIP(mutate) for single-element position changes. For multi-element moves, read before/after rects around the mutation yourself and apply CSS transforms — the FLIP technique works the same way.

// Use CSS `order` to swap visual position — NO DOM mutation.
// DOM moves trigger connectedCallback on fluid-card descendants, which
// restarts the emerge animation from opacity 0 (the "ghost" effect).
const rA = wrapA.getBoundingClientRect(), rB = wrapB.getBoundingClientRect()
const aOrder = parseInt(wrapA.style.order)
wrapA.style.order = aOrder === 0 ? '1' : '0'  // toggle visual order
wrapB.style.order = aOrder === 0 ? '0' : '1'
const dxA = rA.left - wrapA.getBoundingClientRect().left
const dxB = rB.left - wrapB.getBoundingClientRect().left
wrapA.style.transform = \`translateX(\${dxA}px)\`
wrapB.style.transform = \`translateX(\${dxB}px)\`
void wrapA.offsetWidth  // force style flush
wrapA.style.transition = wrapB.style.transition = 'transform 450ms cubic-bezier(0.34,1.15,0.64,1)'
wrapA.style.transform = wrapB.style.transform = ''
