fluid-theme

Token provider element. Sets --fluid-* custom properties on itself. Dispatches fluidtheme:change. Use FluidTheme.setGlobalMode() to switch dark/light/system globally without needing an element.

Variants

Default (no attributes)

Inherits global token defaults.

System defaults
 
<fluid-theme>
  <!-- children inherit --fluid-* tokens -->
</fluid-theme>

Custom brand-hue="280" (violet)

Overrides --fluid-hue-brand to 280.

Violet brand (hue 280)
 
<fluid-theme brand-hue="280"></fluid-theme>

Custom font-family

Custom font via font-family attribute. 

<fluid-theme font-family="'Georgia', serif"></fluid-theme>

States

Dark mode via data-theme attribute

data-theme="dark" on fluid-theme 
<fluid-theme data-theme="dark"></fluid-theme>

Edge cases

Invalid brand-hue (dev warning)

Setting brand-hue="banana" logs a [fluid warn] to the console and retains the prior valid value. Open DevTools Console to see it.
