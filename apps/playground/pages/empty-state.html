Empty State

An illustrated indicator of absence. Composes fluid-card as the glass surface — Layer 1 (Surface), thin material. Headline and description are string attributes for predictable accessible naming. Illustration supports a URL attribute or a custom element via the illustration slot.

Glass tier

Toggle the Tier control in the toolbar to see the glass material change. Matte is opaque with no blur. Frosted adds backdrop-filter: blur. Crystalline samples the background luminance to tint the surface.

States

fluid-empty-state has one state: idle. It is the indicator of absence and does not carry loading or error state itself. The parent container decides when to show it. The fluid-button elements in the actions slot carry their own states.

Clear filters Syncing… Create item Request access 
<!-- The empty state itself is always idle.
     Action buttons carry their own loading/disabled states. -->
<fluid-empty-state headline="Syncing data" description="…">
  <fluid-button slot="actions" variant="primary" loading>Syncing…</fluid-button>
</fluid-empty-state>
