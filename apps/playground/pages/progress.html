Progress

A role="progressbar" component with linear and circular variants. Determinate mode visualises a specific value; omit value to enter indeterminate mode with a continuous animation.

Edge cases

Value clamping (out-of-bounds values)

value="-50" → 0%
value="200" → 100% 
<!-- Values outside [min, max] are clamped -->
<fluid-progress value="-50"></fluid-progress>  <!-- renders as 0% -->
<fluid-progress value="200"></fluid-progress>  <!-- renders as 100% -->

Custom min / max

Step 3 of 8 
<fluid-progress
  aria-label="Step 3 of 8"
  aria-valuetext="Step 3 of 8"
  min="0" max="8" value="3"
></fluid-progress>

// Animate value updates — CSS transition on width handles the visual motion
const bar = document.querySelector('#pg-progress-animated')
let pct = 0
const interval = setInterval(() => {
  pct = Math.min(100, pct + 5)
  bar.setAttribute('value', String(pct))
  if (pct >= 100) clearInterval(interval)
}, 120)

Tier effects

The progress component adjusts its mount animation and indeterminate behaviour based on the active performance tier. Switch tiers in the toolbar and toggle the indeterminate progress below to observe mount behaviour.

  • Matte — no emerge spring on mount; indeterminate animation runs as a CSS-only sliding fill.
  • Frosted / Crystalline / Optical — emerge spring (scale + fade) plays when the component mounts.

The Reduced motion toolbar toggle pauses the indeterminate animation via --fluid-animation-play-state: paused cascading into the Shadow DOM.
