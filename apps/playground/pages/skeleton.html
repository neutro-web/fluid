Skeleton

A decorative loading placeholder. Renders a shimmer animation over a muted surface to signal that content is on its way. Marked aria-hidden="true" so screen readers skip it entirely — pair with aria-busy or a live region on the container to communicate loading state accessibly.

Variants

<fluid-skeleton variant="rectangular" width="240px" height="40px"></fluid-skeleton>
<fluid-skeleton variant="circular" width="56px" height="56px"></fluid-skeleton>
<!-- variant="text" defaults height to 1em -->
<fluid-skeleton variant="text" width="280px"></fluid-skeleton>
<fluid-skeleton variant="text" width="240px"></fluid-skeleton>
<fluid-skeleton variant="text" width="180px"></fluid-skeleton>

States

The shimmer animation runs indefinitely while the skeleton is mounted. At prefers-reduced-motion: reduce, the animation stops and only the muted background remains — verifiable by enabling the OS reduced motion setting. 

<!-- Compose skeletons to match the real layout -->
<fluid-card>
  <fluid-skeleton variant="circular" width="44px" height="44px"></fluid-skeleton>
  <fluid-skeleton variant="text" width="60%"></fluid-skeleton>
  …
</fluid-card>

Edge cases

Without explicit dimensions the skeleton collapses — set at least one axis via width / height or size it via CSS on a parent: 

<!-- Size via parent -->
<div style="width:200px;height:20px">
  <fluid-skeleton style="width:100%;height:100%"></fluid-skeleton>
</div>
<!-- Full-width banner skeleton -->
<fluid-skeleton variant="rectangular" width="100%" height="80px"></fluid-skeleton>

variant="text" inherits font-size from context (1em = 18px here): 

<!-- height defaults to 1em — scales with surrounding font-size -->
<div style="font-size:18px">
  <fluid-skeleton variant="text" width="200px"></fluid-skeleton>
</div>

Tier effects

The shimmer animation and mount spring are both tier-gated. Use the toolbar above to switch tiers and observe the differences.

  • Matte — no shimmer (the gradient overlay is off), no emerge spring. Only the muted background colour remains.
  • Frosted / Crystalline / Optical — shimmer enabled, plus the emerge spring (scale + fade) plays on each mount.

The Reduced motion toolbar toggle pauses the shimmer animation (via --fluid-animation-play-state: paused cascading into the Shadow DOM). The OS reduced-motion preference removes the shimmer entirely via @media (prefers-reduced-motion: reduce).

Switch to Matte in the toolbar to see the shimmer-off state.

Glass effect on coloured backgrounds

The skeleton's glass material becomes more visible against coloured or photographic backgrounds — the frosted translucency and shimmer stand out compared to a flat neutral canvas. This matches Axiom 3 ("Layered surfaces"), where glass layers are designed to sit above content, not replace it.

Switch to Frosted or higher tiers to see the glass shimmer over the gradient below. 

<!-- skeleton over a coloured gradient background -->
<div style="background: linear-gradient(135deg, …)">
  <fluid-skeleton variant="circular" width="52px" height="52px"></fluid-skeleton>
  <fluid-skeleton variant="rectangular" width="100%" height="120px"></fluid-skeleton>
  …
</div>
