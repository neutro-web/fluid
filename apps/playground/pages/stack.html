Stack

Flexbox layout primitive. The host element IS the flex container — no shadow DOM. Compose vertical or horizontal layouts with gap tokens, alignment, wrapping, and smooth FLIP animation when children reorder.

Direction

Default is vertical. Set direction="horizontal" for a row.

vertical (default)

direction="horizontal"

 
<!-- Vertical (default) -->
<fluid-stack>
  <div>...</div>
  <div>...</div>
  <div>...</div>
</fluid-stack>

<!-- Horizontal -->
<fluid-stack direction="horizontal">
  <div>...</div>
  <div>...</div>
  <div>...</div>
</fluid-stack>

Gap

Five named tokens: xs (4px), sm (8px), md (16px, default), lg (24px), xl (40px). Also accepts any CSS length.

gap="xs" — 4px

gap="sm" — 8px

gap="md" — 16px (default)

gap="lg" — 24px

gap="xl" — 40px

 
<fluid-stack direction="horizontal" gap="xs">...</fluid-stack>
<fluid-stack direction="horizontal" gap="sm">...</fluid-stack>
<fluid-stack direction="horizontal" gap="md">...</fluid-stack>
<fluid-stack direction="horizontal" gap="lg">...</fluid-stack>
<fluid-stack direction="horizontal" gap="xl">...</fluid-stack>

Align

Controls align-items on the flex container. Boxes of different heights make alignment visible.

align="stretch" (default)

align="center"

align="start"

align="end"

 
<fluid-stack direction="horizontal" align="stretch">...</fluid-stack>
<fluid-stack direction="horizontal" align="center">...</fluid-stack>
<fluid-stack direction="horizontal" align="start">...</fluid-stack>
<fluid-stack direction="horizontal" align="end">...</fluid-stack>

Justify

Controls justify-content. Fixed-width container makes distribution visible.

justify="start" (default)

justify="center"

justify="end"

justify="space-between"

 
<fluid-stack direction="horizontal" justify="start">...</fluid-stack>
<fluid-stack direction="horizontal" justify="center">...</fluid-stack>
<fluid-stack direction="horizontal" justify="end">...</fluid-stack>
<fluid-stack direction="horizontal" justify="space-between">...</fluid-stack>

Wrap

Boolean attribute wrap enables flex-wrap: wrap. Resize the window to see boxes reflow.

 
<fluid-stack direction="horizontal" gap="sm" wrap>

  <div>...</div>
  <div>...</div>
  <div>...</div>

  <div>...</div>
  <div>...</div>
  <div>...</div>
  <div>...</div>
</fluid-stack>

Layout animation

The layout attribute enables FLIP animation when children reorder. Tier-aware: CSS transitions for Matte/Frosted, WAAPI for Crystalline/Optical.

2
3
4 
<fluid-stack id="flip-demo" layout direction="horizontal" gap="sm">
  <div>1</div>
  <div>2</div>
  <div>3</div>
  <div>4</div>
</fluid-stack>

<script>
  document.getElementById('shuffle-btn').addEventListener('click', () => {
    const s = document.getElementById('flip-demo')
    const ch = [...s.children]
    for (let i = ch.length - 1; i > 0; i--) {
      const j = Math.floor(Math.random() * (i + 1))
      s.appendChild(ch[j])
      ch.splice(j, 1)
    }
  })
</script>

RTL

Inside a dir="rtl" container, direction="horizontal" auto-reverses visually — no extra attributes needed.

LTR (default) — order: 1 2 3 4

1
2
3
4

dir="rtl" — visually reversed: 4 3 2 1

1
2
3
4
 
<!-- LTR: order 1 2 3 4 -->
<fluid-stack direction="horizontal" gap="sm">
  <div>1</div><div>2</div><div>3</div><div>4</div>
</fluid-stack>

<!-- RTL: visually reversed, no extra attrs -->
<div dir="rtl">
  <fluid-stack direction="horizontal" gap="sm">
    <div>1</div><div>2</div><div>3</div><div>4</div>
  </fluid-stack>
</div>

Edge Cases

Empty stack — renders as an empty flex container, no layout side-effects.

<fluid-stack><!-- no children --></fluid-stack>

Very long content — children overflow; use wrap or clip with overflow:hidden on the stack.

This label is extremely long and will overflow
Another very long one
 
<fluid-stack direction="horizontal" gap="sm" style="overflow:hidden">
  <div>Very long content...</div>
  <div>Another one</div>
</fluid-stack>

Minimum size — stack collapses to its children's minimum size. Constrain with min-width if needed.

 
<fluid-stack direction="horizontal" gap="sm" style="min-width:200px">
  <div>...</div>
</fluid-stack>

Container query — fluid-stack has container-type: inline-size. Descendants can use @container to respond to the stack's width.

Adapts to stack width
 
/* In consumer CSS: */
@container (max-width: 300px) {
  .cq-box { background: #ef4444; }
}
