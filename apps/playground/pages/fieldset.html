Fieldset

Semantic form group with a glass header surface and legend. The legend attribute is linked to the inner <fieldset> via aria-labelledby. When disabled, the header dims and the component propagates disabled context to nested fluid form inputs and buttons.

Default

Cancel Save 
<fluid-fieldset legend="Personal information">
  ...form controls...
  <fluid-button variant="primary">Save</fluid-button>
</fluid-fieldset>

Disabled state

The header opacity drops to 0.5 and pointer events are blocked. Child fluid-button elements receive the disabled context automatically — no disabled attribute needed on each child.

Cancel Update address 
<!-- fluid-button gets disabled context automatically -->
<fluid-fieldset legend="Billing address" disabled>
  ...
  <fluid-button variant="primary">Update address</fluid-button>
</fluid-fieldset>

Header actions

Use slot="header-actions" to place controls in the glass header area — typically icon buttons.

Save preferences 
<fluid-fieldset legend="Notification settings">
  <fluid-icon-button slot="header-actions" variant="ghost" size="sm" aria-label="Edit">
    ...icon...
  </fluid-icon-button>
  ...controls...
  <fluid-button variant="primary">Save preferences</fluid-button>
</fluid-fieldset>

Legend slot

For rich legend content (icons, badges), use slot="legend" instead of the legend attribute. The slot content replaces the text and is still used for the aria-labelledby link.

Schedule
Clear Apply 
<fluid-fieldset>
  <span slot="legend">
    <svg ...>...</svg>
    Schedule
  </span>
  ...controls...
</fluid-fieldset>

Nested fieldsets

Fieldsets can be nested. Each provides its own context scope — the disabled Security group disables its own fluid-button children without affecting the outer group.

Save profile
Cancel Change password 
<fluid-fieldset legend="Account settings">
  <fluid-fieldset legend="Profile">
    ...
    <fluid-button variant="primary">Save profile</fluid-button>
  </fluid-fieldset>
  <fluid-fieldset legend="Security" disabled>
    <!-- fluid-button gets disabled context automatically -->
    <fluid-button variant="primary">Change password</fluid-button>
  </fluid-fieldset>
</fluid-fieldset>

Edge cases

Toggle disabled

Removing the disabled attribute restores the header and pushes DISABLED_CONTEXT_KEY=false to all subscribed child fluid components.

Confirm payment
Disable group Enable group 
// Disable — fluid-button children receive context push automatically
fieldset.setAttribute('disabled', '')

// Enable
fieldset.removeAttribute('disabled')

Missing legend

In development builds, mounting fluid-fieldset without a legend attribute or slot="legend" content emits a console.warn after the first animation frame. 

<!-- ⚠️  Dev warns: legend attribute or legend slot required -->
<fluid-fieldset>...</fluid-fieldset>

<!-- ✅ Attribute -->
<fluid-fieldset legend="My group">...</fluid-fieldset>

<!-- ✅ Slot -->
<fluid-fieldset>
  <span slot="legend">My group</span>
  ...
</fluid-fieldset>
