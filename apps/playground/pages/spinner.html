Spinner

A CSS-animated loading indicator with a rotating arc. Uses role="status" and aria-label to announce loading state to assistive technologies. Switches to a pulsing opacity animation when prefers-reduced-motion is active.

Sizes

Three sizes cover common use cases — sm for inline/button contexts, md as the default, and lg for full-section or empty-state loaders.

sm — 16px
md — 24px (default)
lg — 36px 
<fluid-spinner size="sm" aria-label="Loading"></fluid-spinner>
<fluid-spinner size="md" aria-label="Loading"></fluid-spinner>
<fluid-spinner size="lg" aria-label="Loading"></fluid-spinner>

Edge cases

Button loading state

Use fluid-button[loading] for the built-in loading variant, or compose a spinner manually when you need a custom button appearance.

Save changes Processing 
<!-- fluid-button with built-in loading state -->
<fluid-button loading variant="primary">Save changes</fluid-button>

<!-- Manual composition -->
<button type="button" aria-busy="true" aria-label="Uploading file">
  <fluid-spinner size="sm" aria-label="Uploading"></fluid-spinner>
  Uploading…
</button>

<fluid-card>
  <div slot="header">
    <h2>Analytics</h2>
    <fluid-spinner size="sm" aria-label="Refreshing analytics data"></fluid-spinner>
  </div>
  Fetching data…
</fluid-card>

Verbose accessible label

The aria-label is not visible — it only affects screen readers. A detailed label improves context without cluttering the UI. 

<fluid-spinner
  size="md"
  aria-label="Analyzing your document — this may take up to 30 seconds depending on file size"
></fluid-spinner>

Tier effects

The spinner adjusts its mount/unmount behaviour based on the active performance tier (set via the toolbar above). Switch tiers and toggle the spinner below to observe the difference.

  • Matte — spins in and out immediately, no spring animation on mount/unmount.
  • Frosted / Crystalline / Optical — emerge spring (scale + fade) plays on mount; recede plays on unmount.
Hide spinner Show spinner

Tip: the emerge/recede spring is only visible on Frosted+ tiers. The Reduced motion toolbar toggle pauses all spinner animations.
