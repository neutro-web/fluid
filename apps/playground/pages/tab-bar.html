Tab Bar

ARIA-compliant tablist compound component. Composed of fluid-tab-bar, fluid-tab, and fluid-tab-panel. Supports horizontal and vertical orientations, automatic and manual activation, disabled tabs, and controlled mode via active-tab.

Horizontal (default)

Default orientation. Arrow keys navigate between tabs; the selected tab's panel is shown below the tab list.

Overview Details Settings
Overview panel — Fluid is a tier-aware design system that adapts its motion fidelity to available device resources.
Details panel — Components expose design tokens as CSS custom properties, ensuring full theme-ability without shadow-piercing hacks.
Settings panel — The FluidLedger measures frame-rate and device memory to automatically select the appropriate motion tier at runtime.
 
<fluid-tab-bar aria-label="Example tabs">
  <fluid-tab tab-id="t1" panel="p1">Overview</fluid-tab>
  <fluid-tab tab-id="t2" panel="p2">Details</fluid-tab>
  <fluid-tab tab-id="t3" panel="p3">Settings</fluid-tab>
  <fluid-tab-panel slot="panel" panel-id="p1">Overview panel content.</fluid-tab-panel>
  <fluid-tab-panel slot="panel" panel-id="p2">Details panel content.</fluid-tab-panel>
  <fluid-tab-panel slot="panel" panel-id="p3">Settings panel content.</fluid-tab-panel>
</fluid-tab-bar>

Vertical

Set orientation="vertical" to render the tab list along the side. Up/Down arrow keys navigate; Left/Right are not used.

Overview Details Settings
Overview — Fluid adapts its motion fidelity to available device resources in real time.
Details — CSS custom properties carry design tokens from a portal outward to all descendant components.
Settings — FluidLedger benchmarks paint timings on first render and re-evaluates on subsequent idle callbacks.

Manual activation

With activation="manual", arrow keys move focus without selecting. Press Enter or Space to activate the focused tab.

Disabled tab

A tab with the disabled attribute is skipped during keyboard navigation and cannot be activated.

Overview Details (disabled) Settings
Overview — navigate with arrow keys; the disabled Details tab is skipped.
Details — this panel is unreachable while its tab is disabled.
Settings — you jumped here directly from Overview.

Controlled mode

Pass active-tab to own the active state. Listen to fluid:change and update the attribute to keep it in sync. The event log below shows the emitted detail.

Overview Details Settings
Overview — the parent controls which tab is active via the active-tab attribute.
Details — on tab change, fluid:change fires and the host updates active-tab to match.
Settings — controlled mode is useful when you need to persist or validate the active tab externally.
