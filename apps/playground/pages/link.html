Link

A styled, token-aware anchor primitive. No glass surface, no spring interaction — intentionally minimal for composability (breadcrumb, sidebar, nav). Uses a shadow <a> for native link semantics, keyboard behavior, and "open in new tab".

Variants

Default link 
<fluid-link href="/about">About us</fluid-link>
Open Google 
<fluid-link href="https://www.google.com" target="_blank">
  <svg slot="icon" ...></svg>
  External resource
</fluid-link>

States

Default Current page Disabled 
<fluid-link href="/">Default</fluid-link>
<fluid-link href="/" current>Current page</fluid-link>
<fluid-link disabled>Disabled</fluid-link>

In a nav context

Link-based navigation: aria-current="page" on the active crumb.

Home Products Link Contact 
<nav aria-label="Site navigation">
  <fluid-link href="/">Home</fluid-link>
  <fluid-link href="/products">Products</fluid-link>
  <fluid-link href="/link" current>Link</fluid-link>
</nav>

Edge cases

Icon-only with aria-label — no text, explicit label for screen readers.

<fluid-link href="/" aria-label="Home">
  <svg slot="icon" aria-hidden="true">...</svg>
</fluid-link>

External link (target="_blank") — rel="noopener noreferrer" applied automatically.

Open Google 
<fluid-link href="https://www.google.com" target="_blank">
  Open Google
</fluid-link>
<!-- rel="noopener noreferrer" applied automatically -->

JS-driven navigation — no href, still focusable.

Navigate via JS 
<fluid-link>Navigate via JS</fluid-link>
<!-- tabindex="0" and role="link" applied automatically -->

RTL — icon and text mirror under dir="rtl".

رابط خارجي 
<div dir="rtl">
  <fluid-link href="#">
    <svg slot="icon" ...></svg>
    رابط خارجي
  </fluid-link>
</div>
