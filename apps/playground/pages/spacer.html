Spacer

Flexible whitespace element for use inside fluid-stack. Invisible by default — demos use a tinted background so the spacer's shape and size are visible. Always aria-hidden="true"; no shadow DOM.

Grow

A grow spacer sets flex: 1 1 0px, consuming all remaining space in the stack. Use it to push siblings to opposite ends or to distribute space evenly.

 
<fluid-stack direction="horizontal">
  <div class="box"></div>
  <fluid-spacer grow></fluid-spacer>
  <div class="box"></div>
</fluid-stack>
 
<!-- Equal grow spacers distribute space evenly -->
<fluid-stack direction="horizontal">
  <div class="box"></div>
  <fluid-spacer grow></fluid-spacer>
  <div class="box"></div>
  <fluid-spacer grow></fluid-spacer>
  <div class="box"></div>
</fluid-stack>

Fixed Size

The size attribute accepts a token (xs, sm, md, lg, xl) or any arbitrary CSS length. It sets both width and height to that value.

xs — 4px
sm — 8px
md — 16px
lg — 24px
xl — 40px 
<fluid-spacer size="xs"></fluid-spacer>  <!-- 4px  -->
<fluid-spacer size="sm"></fluid-spacer>  <!-- 8px  -->
<fluid-spacer size="md"></fluid-spacer>  <!-- 16px -->
<fluid-spacer size="lg"></fluid-spacer>  <!-- 24px -->
<fluid-spacer size="xl"></fluid-spacer>  <!-- 40px -->
 
<!-- Arbitrary CSS length -->
<fluid-spacer size="36px"></fluid-spacer>

Axis

The axis attribute restricts which dimension the size is applied to. The tinted background makes the spacer's actual footprint obvious.

axis="horizontal" — width only
Gap fills horizontally; height matches its container
axis="vertical" — height only
Gap fills vertically; width matches its container
default — both axes (square)
Fixed 16×16 square gap — useful between grid cells 
<!-- Horizontal gap only (push siblings apart in a row) -->
<fluid-spacer size="md" axis="horizontal"></fluid-spacer>

<!-- Vertical gap only (push siblings apart in a column) -->
<fluid-spacer size="md" axis="vertical"></fluid-spacer>

<!-- Both axes — fixed square gap (default, no axis attribute) -->
<fluid-spacer size="md"></fluid-spacer>
