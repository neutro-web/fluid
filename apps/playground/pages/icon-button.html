Icon Button

Circular icon-only button. Spring press deformation (scale 0.94) with per-instance ripple canvas at Frosted+. aria-label is required — a FluidError fires in dev if absent. Touch target enforced at minimum 48×48px (WCAG 2.5.5).

Sizes

All sizes enforce a minimum 48×48px touch target (WCAG 2.5.5). sm and md both render at 48px — the touch target is clamped to the WCAG minimum. sm uses a smaller icon (16px) within the same hit area. lg expands to 56px.

aria-label — dev enforcement

In development builds, mounting fluid-icon-button without aria-label throws a FluidError at connect time. In production, a one-time console.warn fires instead. All examples on this page include aria-label. 

<!-- ❌ Dev throws FluidError -->
<fluid-icon-button>...</fluid-icon-button>

<!-- ✅ Correct usage -->
<fluid-icon-button aria-label="Close">...</fluid-icon-button>
